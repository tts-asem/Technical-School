المجلد الأساسي الذي ستنشأ تحته مجلدات الطلاب والمعلمين

كيف تحصل على Client ID الخاص بحسابك لربطه بالموقع مجاناً؟

  1. افتح بوابة مايكروسوفت: portal.azure.com وسجل بحساب مدرستك أو حسابك الشخصي.
  2. اضغط على New registration (تسجيل جديد)، واكتب اسم التطبيق (مثل: Mawhiba Cloud Portal).
  3. في خيار Supported account types اختر: Accounts in any organizational directory and personal Microsoft accounts.
  4. في قسم Redirect URI اختر نوع Single-page application (SPA) وضع رابط موقعك (أو رابط النطاق المجاني الخاص بك على Netlify أو Vercel أو `http://localhost`).
  5. اضغط Register، ثم انسخ Application (client) ID وضعه في الحقل أعلاه واضغط حفظ.
